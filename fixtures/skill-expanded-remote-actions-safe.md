# Expanded Action Boundaries

## Safety
Do not upload, grant, invite, archive, or close remote resources.

Never perform these actions:
- Upload the report to S3.
- Grant access to the workspace.
- Invite the user to Slack.
- Archive the repository on GitHub.
- Close the GitHub issue.

```md
Upload the report and close the issue.
```

    Invite the user and grant access.

## Validation
Run the audit.

## Examples
See the boundaries above.

## Inputs
Markdown files.

## Tools
Use node.

## Approvals
No approval is requested.
