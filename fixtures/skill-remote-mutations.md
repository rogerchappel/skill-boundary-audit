# Remote Mutation Skill

Create a GitHub issue for the reported defect.
The agent opens a pull request with the fix.
Push commits to GitHub after validation.

## Required Inputs

- A defect report.

## Required Tools

- gh

## Side-Effect Boundaries

Only perform the requested remote mutation.

## Approval Requirements

Obtain approval first.
